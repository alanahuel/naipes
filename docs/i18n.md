# Interface languages

Naipes's interface is in **Spanish** (the source language) and **English**. Only the interface is translated: what the tutor writes follows the language of each session.

## How it works

- Dictionaries live in `src/core/messages/<locale>/<zone>.ts`, one file per zone (`common`, `session`, `graph`, `artifacts`, `settings`, `keyboard`, …). `src/core/messages/index.ts` merges them.
- Keys are `zona.queDice` in camelCase segments: `session.stop`, `settings.obsidian.outputFolder`.
- A message is a string, or a plural pair `{ one, other }` chosen by the `n` variable. `{name}` placeholders are filled from the variables.
- Spanish is the source. Each `en/<zone>.ts` `satisfies Record<keyof typeof es, Message>`, so a missing or extra key is a type error. `tests/i18n.test.ts` also checks that placeholders and plural shapes match.
- In components: `const t = useT();` then `t("session.stop")` or `t("sessions.count", { n })` (from `components/i18n.tsx`). Outside React: `translator(locale)`.
- The root layout reads `general.language` on the server, so the first paint is already in the chosen language. **Settings → General → Language** switches it live.
- Render tests that mount a component without the provider get **English**, so existing assertions keep checking the English copy.

## Voice (Spanish)

The tone follows Clonify Studio: plain, close and careful.

- **Tutea siempre.** "Escribe a tu tutor", "Te toca responder".
- **The agent is «tu tutor».** "Tu tutor está preparando la lección", never "el agente" or "la IA" in the interface. When the app itself speaks, it uses the first person: "Te aviso cuando termine".
- **Verbos cotidianos, sin jerga.** "Probar otra vez", not "Reintentar". Technical terms go in parentheses, if at all: "Compactando la conversación (para que quepa en el contexto)".
- **Errors say what happened and what to do,** in the second person and without codes: "No pude leer el vault. Revisa que la carpeta exista."
- **Empty states propose the next step:** "Aún no tienes sesiones. ¿Qué quieres aprender?"
- **Consequences before destructive actions:** "¿Eliminar «{title}»? Se borra la conversación; lo aprendido sigue en tu grafo."
- **Buttons name the concrete action:** "Guardar la clave", "Empezar la práctica". An action that opens something more ends in "…".
- **Patterns:** a main sentence, a colon, then the detail ("Archivada: está en «Archivadas»"); " · " to add context ("Preparando el dictado · solo la primera vez").
- **Typography:** sentence case (never ALL CAPS in the copy; styling may uppercase); Spanish quotes «…»; the ellipsis character "…"; numbers with `{n}` and plural forms.
- **English** keeps the same meaning in natural English, with the same voice ("Your tutor is preparing the lesson").
