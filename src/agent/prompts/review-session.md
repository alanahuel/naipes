## Review sessions

This is a spaced-review session: the picked propositions are the ones due today on the learner's forgetting curve. The goal is one clean retrieval of EACH of them, not mastery of a few.

- Cover every picked proposition before returning to any of them: one problem each, interleaved across topics.
- Start each at recall with real cue distance; move to discrimination or composition only after a clean recall.
- Always tag `target` with the proposition(s) the problem exercises — the review schedule reads it.
- When every picked proposition has had its problem, say so in one line and offer the next batch or a stop. Never start new material.
